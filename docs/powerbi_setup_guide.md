# Power BI Setup Guide
## E-Commerce Sales & Profitability Analytics Dashboard

**Dataset:** `data/cleaned_sales.csv`  
**Power BI Desktop Version:** 2.120+ (July 2023 or later recommended)

---

## Prerequisites

1. **Download Power BI Desktop** (free):  
   https://powerbi.microsoft.com/en-us/desktop/
2. **Cleaned dataset file:** `data/cleaned_sales.csv` must be generated by running `src/data_cleaning.py`
3. **Minimum screen resolution:** 1366×768 for dashboard design

---

## Step 1: Import the Dataset

1. Open **Power BI Desktop**
2. Click **Home → Get data → Text/CSV**
3. Navigate to your project folder: `ecommerce-sales-analysis/data/`
4. Select **`cleaned_sales.csv`**
5. Click **Load** (or **Transform Data** if you want to review first)

### In Power Query Editor (optional validation):
- Confirm **Order Date** column is recognized as `Date` type
- Confirm **Sales**, **Profit**, **Discount** are `Decimal Number`
- Confirm **Quantity** is `Whole Number`
- Click **Close & Apply**

---

## Step 2: Set Up Data Types

In the **Data View** or **Model View**, verify these column types:

| Column | Power BI Data Type | Format |
|--------|-------------------|--------|
| Order Date | Date | Short Date |
| Ship Date | Date | Short Date |
| Sales | Decimal Number | Currency (\$) |
| Profit | Decimal Number | Currency (\$) |
| Quantity | Whole Number | No decimal |
| Discount | Decimal Number | Percentage |
| Profit Margin % | Decimal Number | Percentage (1 decimal) |
| Order Year | Whole Number | No decimal |
| Order Month | Whole Number | No decimal |
| Row ID | Whole Number | No decimal |

### Mark Date Table (optional but recommended):
- Right-click the table → **Mark as Date Table** → select **Order Date**

---

## Step 3: Create DAX Measures

In the **Report View**, click **New measure** (Home tab) and enter each DAX measure below.  
See also: `docs/powerbi_dax_measures.md` for all measures.

### Core KPI Measures:

```dax
Total Sales = SUM('cleaned_sales'[Sales])

Total Profit = SUM('cleaned_sales'[Profit])

Total Quantity = SUM('cleaned_sales'[Quantity])

Total Orders = DISTINCTCOUNT('cleaned_sales'[Order ID])

Profit Margin % = 
DIVIDE([Total Profit], [Total Sales], 0) * 100

Average Order Value = 
DIVIDE([Total Sales], [Total Orders], 0)
```

## Step 4: Build the Dashboard Page

### 4.1 KPI Cards (top row)

Add **4 Card visuals** for:
1. **Total Sales** → Field: `[Total Sales]` → Format: Currency
2. **Total Profit** → Field: `[Total Profit]` → Format: Currency
3. **Total Orders** → Field: `[Total Orders]` → Format: Whole number
4. **Profit Margin %** → Field: `[Profit Margin %]` → Format: 2 decimal places + "%"

### 4.2 Monthly Sales Trend (Line Chart)
- **Visual type:** Line chart
- **X-Axis:** `Order Date` (set to Month level) or `Order Month Name`
- **Y-Axis:** `[Total Sales]`
- **Legend:** `Order Year`
- **Title:** "Monthly Sales Trend"

### 4.3 Sales by Category (Clustered Bar Chart)
- **Visual type:** Clustered bar chart
- **Y-Axis:** `Category`
- **X-Axis:** `[Total Sales]`
- **Title:** "Sales by Category"

### 4.4 Profit by Region (Map or Bar Chart)
- **Visual type:** Clustered bar chart (or Filled Map)
- **Axis/Location:** `Region`
- **Value:** `[Total Profit]`
- **Title:** "Profit by Region"
- **Conditional formatting:** Green for positive, Red for negative profit

### 4.5 Sales by Customer Segment (Donut Chart)
- **Visual type:** Donut chart
- **Legend:** `Segment`
- **Values:** `[Total Sales]`
- **Title:** "Sales by Customer Segment"

### 4.6 Top 10 Products by Sales (Horizontal Bar)
- **Visual type:** Clustered bar chart (horizontal)
- **Y-Axis:** `Product Name`
- **X-Axis:** `[Total Sales]`
- **Filter:** Apply Top N filter → Top 10 by `[Total Sales]`
- **Title:** "Top 10 Products by Sales"

### 4.7 Discount vs Profit (Scatter Chart)
- **Visual type:** Scatter chart
- **X-Axis:** `Discount` (average)
- **Y-Axis:** `[Total Profit]`
- **Details:** `Sub-Category`
- **Title:** "Discount vs Profit"

---

## Step 5: Add Slicers (Filters)

Add **4 Slicer visuals**:

1. **Order Date** → Slicer style: Date range
2. **Region** → Slicer style: Dropdown or List
3. **Category** → Slicer style: List (with checkboxes)
4. **Segment** → Slicer style: List (with checkboxes)

### Slicer Configuration:
- Enable **"Sync slicers"** if you have multiple pages (View → Sync slicers)
- Set **Select all** option in each slicer

## Step 7: Formatting and Theme

1. **Theme:** Go to **View → Themes → Browse for themes** or apply built-in "Innovation" theme
2. **Color palette:** Blue (#2196F3), Green (#4CAF50), Orange (#FF9800)
3. **Font:** Segoe UI 11pt for labels, 14pt bold for titles
4. **Currency format:** `$#,##0.00` for Sales and Profit
5. **Percentage format:** `0.00%` for Profit Margin
6. **Title:** Add a text box at top: "E-Commerce Sales & Profitability Analytics Dashboard"

---

## Step 8: Save and Publish

1. **Save** as: `powerbi/Ecommerce_Sales_Dashboard.pbix`
2. **Publish** (optional): Home → Publish → Select workspace on Power BI Service
3. **Export** report to PDF: File → Export → Export to PDF (for submission)

---

## Troubleshooting

| Issue | Solution |
|-------|---------|
| Dates not parsing correctly | In Power Query, select Order Date → Change Type → Date |
| "Cannot display visual" error | Check that measures reference the correct table name |
| Profit Margin % shows wrong values | Ensure it uses DIVIDE([Total Profit],[Total Sales],0)*100 not average of individual margins |
| Slicer not affecting all visuals | Use View → Sync Slicers and enable all pages |
