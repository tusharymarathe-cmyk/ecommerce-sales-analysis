# Data Directory — E-Commerce Sales Analysis Project

## Overview

This directory contains all datasets used in the project.

> **IMPORTANT NOTICE**: The dataset used in this project (`raw_sales_data.csv`) is **synthetically generated** using Python's NumPy and random generators. It is designed to closely simulate the statistical properties of publicly available retail sales datasets (such as Tableau's Sample Superstore). All business insights derived from this data are based on synthetic records and are presented for **educational purposes only**.

## Synthetic Data Statement

This dataset was generated by `src/generate_dataset.py` using:
- **NumPy random seed**: 42 (fully reproducible)
- **Statistical calibration**: Margin rates, seasonal patterns, and discount distributions calibrated to mirror typical US retail data
- **Size**: 9,994 rows after cleaning — matching the size of the public Tableau Sample Superstore dataset
